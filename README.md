# 🤖 Multimodal AI Assistant

A modern AI-powered chatbot built with **Next.js**, **TypeScript**, and **Tailwind CSS**. The assistant supports intelligent conversations, Markdown rendering, image uploads, and a clean ChatGPT-inspired interface.

### ✨ Features

* 💬 AI-powered chat
* 🖼️ Image upload support
* 📝 Markdown responses
* 🔐 User authentication
* 🌙 Modern responsive UI
* 📂 Chat history sidebar

### 🛠️ Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Shadcn/UI
* NextAuth.js
* OpenAI API

### 🚀 Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
